# واژه‌نامه نگارش
# خط اول قاعده، بعد نمونه‌ها. رادار موقع نوشتن به این فایل نگاه می‌کند.

نام محصول، افزونه و شرکت را لاتین بنویس. مخاطب با همان اسم جست‌وجو می‌کند.
واژه‌های روزمره را فارسی بنویس، نه لاتین. اصطلاح فنی نام است، نه واژهٔ روزمره؛
آن هم لاتین می‌ماند.

لاتین می‌مانند:
Elementor, WooCommerce, Yoast, Rank Math, Jetpack, Kinsta, Divi, ACF, Gutenberg, Figma, Lovable, Bolt, v0, MCP, Cursor, Notion, Canva

فارسی نوشته می‌شوند:
WordPress = وردپرس
plugin = افزونه
theme = قالب
page = برگه
post = نوشته
block = بلوک
backup = پشتیبان‌گیری
update = به‌روزرسانی
release = انتشار نسخه
free tier = نسخه رایگان
prompt = پرامپت
agent = ایجنت

اصطلاح را لفظ‌به‌لفظ ترجمه نکن. اصطلاح، نام است؛ لاتین می‌ماند و اگر لازم
بود در همان جمله یک نیم‌جمله معنی‌اش را می‌گوید. معادل فارسی از خودت نساز.
vibe coding = به لاتین می‌ماند؛ یعنی ساختن برنامه با حرف زدن با هوش مصنوعی
open source = به لاتین می‌ماند (اوپن سورس)؛ «منبع باز» و «متن‌باز» غلط است
open weights = به لاتین می‌ماند
context window = به لاتین می‌ماند؛ معنی: حافظهٔ کوتاه‌مدت مدل
fine-tuning = به لاتین می‌ماند
inference = به لاتین می‌ماند
prompt engineering = پرامپت‌نویسی
benchmark = بنچمارک
