# تریگر پشتیبان (Cloudflare Workers)

هدف: اگر `cron-job.org` خوابید یا حسابش بسته شد، رادار نخوابد.

## چطور کار می‌کند

یک ورکر روی لبه کلادفلر، هر ۱۵ دقیقه یک درخواست `POST` به API گیت‌هاب می‌زند و ورک‌فلو `radar-auto` را صدا می‌زند. توکن در متغیر مخفی ورکر نگه داشته می‌شود، نه در کد.

## زمان‌بندی

```
7,22,37,52 * * * *
```

هفت دقیقه بعد از تریگر اصلی، تا دو اجرا هم‌زمان نشوند.

## نصب، از پنل کلادفلر

1. حساب بساز (ایمیل، بدون کارت) در `dash.cloudflare.com`
2. بخش `Workers & Pages` → `Create` → `Worker`
3. محتوای `worker.js` را جای کد پیش‌فرض بگذار و `Deploy` بزن
4. در `Settings` → `Variables and Secrets` یک متغیر مخفی بساز:
   - نام: `GH_TOKEN`
   - مقدار: توکن fine-grained با دسترسی `Actions: write` روی همین مخزن
5. در `Settings` → `Triggers` → `Cron Triggers` این را اضافه کن:
   - `7,22,37,52 * * * *`
6. تست: آدرس خود ورکر را در مرورگر باز کن. باید `{"status":204}` ببینی.

## نکته

هر دو تریگر می‌توانند هم‌زمان فعال باشند. اگر یکی از کار افتاد، دیگری کار را ادامه می‌دهد. اجرای تکراری هم ضرری ندارد، چون رادار خودکار از `state/schedule.json` می‌فهمد چه چیزی وقتش رسیده و چه چیزی نه.
